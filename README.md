# FileManager 下載

輕量、免安裝的 Windows 雙窗格檔案管理工具。目前最新版本：**v1.26.0**

## ⬇ 直接下載最新版（點一下就開始下載）

| 下載 | 名稱 | 大小 | 適用電腦 |
|---|---|---|---|
| **[FileManager-Portable.exe](https://github.com/leowei813/FileManager-Releases/releases/latest/download/FileManager-Portable.exe)** | 可攜版（建議） | 約 71 MB | 任何 Windows 10 / 11（64 位元），不用另外裝任何東西 |
| **[FileManager-Lite.exe](https://github.com/leowei813/FileManager-Releases/releases/latest/download/FileManager-Lite.exe)** | 精簡版 | 約 7 MB | Windows 10（2019 年 5 月之後的更新）/ 11，使用 Windows 內建的 .NET Framework 4.8 |

下載**其中一個** exe 即可：兩個功能完全相同，都不需安裝，點兩下就能開。

- 版本說明與歷史版本：**[最新版本頁面](https://github.com/leowei813/FileManager-Releases/releases/latest)**
- 檔名固定不含版本號；版本請看程式標題列。1.7.0 以後的版本可在程式內「檢查更新」自動更新。
- 第一次開啟若出現「Windows 已保護您的電腦」：點「其他資訊」→「仍要執行」（程式未購買數位簽章憑證）。
